# 日落海岸 · Solana Coast

[打开游戏](https://huangama666.github.io/solana-coast/) · [下载独立离线版](https://huangama666.github.io/solana-coast/offline.html)

使用 Three.js 和 WebGL 2 制作的单人海滨城市游戏。支持手机横竖屏和桌面浏览器。可以在海滨大道步行、奔跑、接委托，在私人车库更换跑车、摩托和快艇。私人跑车配有专属引擎盖贴、车门贴及前后车牌，车库内可点「车牌」看近景。

| 操作 | 手机 | 电脑 |
| --- | --- | --- |
| 步行或奔跑 | 轻推左摇杆走，推满跑。按住「奔跑」也可向前跑 | WASD 或方向键移动，持续按住自动奔跑，Shift 加方向键立即奔跑 |
| 转向、加速、倒车 | 左摇杆转向，右手按油门或倒车 | A / D 转向，W / S 加速或倒车 |
| 手刹 | 手刹按钮 | 空格 |
| 上下车、交谈或交车、出拳 | 对应的屏幕按钮 | F、E、J |
| 环顾或切换视角 | 滑动画面或点「视角」 | 拖动鼠标或按 C |
| 车库、地图、暂停 | 点「车库」、小地图或暂停按钮 | U、M、Esc |

在线版会按设备加载模型。离线游玩可保存上方链接的单文件版本，用支持 WebGL 2 的浏览器打开。
