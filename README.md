# 日落海岸 · Solana Coast

使用 Three.js 与 WebGL 2 制作的海滨城市驾驶游戏。可以徒步探索、接受委托，也可以在私人车库切换跑车、摩托和快艇。

[直接进入游戏](https://huangama666.github.io/solana-coast/)

| 操作 | 按键 |
| --- | --- |
| 移动或驾驶 | WASD / 方向键 |
| 上下车 | F |
| 私人车库 | U |
| 交谈或交车 | E |
| 出拳 | J |
| 切换视角 | C |
| 地图 | M |

移动设备可使用屏幕上的操作按钮。首次进入需要加载角色、载具和城市模型。也可以下载仓库中的 index.html，使用支持 WebGL 2 的浏览器离线游玩。
