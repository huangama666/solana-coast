# GTA AI 版

[打开游戏](https://huangama666.github.io/solana-coast/) · [下载独立离线版](https://huangama666.github.io/solana-coast/offline.html)

使用 Three.js 和 WebGL 2 制作的单人海滨城市游戏。支持手机横竖屏和桌面浏览器。可以在海滨大道步行、奔跑、接委托，开局驾驶私人跑车。车库可切换跑车、摩托、坦克、快艇和直升机。私人跑车配有专属引擎盖贴、车门贴及前后车牌，车库内可点「车牌」看近景。打开「公路跑车 → 定制车身」即可修改牌号或从相册选择车贴，保存后会在当前浏览器保留。两项均可单独恢复，默认使用小狗车贴和「V 我：ama_huangama」车牌。

| 操作 | 手机 | 电脑 |
| --- | --- | --- |
| 步行或奔跑 | 轻推左摇杆走，推满跑。按住「奔跑」也可向前跑 | WASD 或方向键移动，持续按住自动奔跑，Shift 加方向键立即起跑，X 加方向键保持步行 |
| 转向、加速、倒车 | 左摇杆转向，右手按油门或倒车 | A / D 转向，W / S 加速或倒车 |
| 汽车与直升机变形 | 在空旷处点「变直升机」，降落后点「变回汽车」 | H |
| 飞行 | 摇杆前后移动、左右转向，按住「上升」或「下降」 | W / S 前后，A / D 转向，空格上升，X 下降 |
| 手刹 | 手刹按钮 | 空格 |
| 上下车、交谈或交车、出拳 | 对应的屏幕按钮 | F、E、J |
| 行驶中弃车、离船 | 点「弃乘」 | F |
| 拔枪、收枪和射击 | 徒步点「持枪」，再点「开火」。驾驶坦克点「开炮」 | G 拔枪或收枪，J 或单击游戏画面开火，拖动可环顾 |
| 便利店 | 点「商店」或在绿色地图标记旁点「购物」 | B，或在店门口按 E |
| 环顾或切换视角 | 滑动画面或点「视角」 | 拖动鼠标或按 C |
| 车库、地图、暂停 | 点「车库」、小地图或暂停按钮 | U、M、Esc |

海岸便利店全天营业。消星券每张 $75，立即减一颗通缉星。能量饮料每瓶 $25，提升 30 秒的冲刺速度。车辆可以驶过倒地行人，行驶中弃车后车辆会滑行减速。在海上跳船后可以游回海滩。

打开游戏后，霓虹进度条显示当前设备的素材加载进度，城市首帧绘制完成后即可进入。沿海街区共有十种建筑立面，包括汽车旅馆、面包店、唱片店、船具仓库、药房和阳台公寓。手枪和坦克炮会标出并辅助瞄准视野内未被遮挡的目标。路人和巡警均可被击毙。巡警增援从其他街口赶来。坦克的两侧履带沿引擎盖和车顶爬升，偏向一侧驶入时车身会侧倾。受压车辆的悬挂会下沉，驶离后回弹。路口斑马线印有双向可读的「黄啊码」水印。

一次击杀、首次夺取一辆车、首次用坦克压上一辆汽车各记一起案件。停在车顶、倒车或再次开上同一辆车都不会重复计数。累计 2 起出动巡警，5 起加入警车，10 起加入空中搜索的警用直升机。空枪不会增加案件数。甩掉追捕或被捕后，本轮记录清零。
